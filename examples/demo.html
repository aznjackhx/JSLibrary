Appendix — what this exercises

Fragmentation

Page breaks chosen by the library, never mid-line. Table headers and footers repeated on every page the table spans. Figures and callouts kept whole. Orphan and widow control on paragraphs. This appendix begins on a fresh page because of break-before: page.

Page furniture

A4 with millimetre margins from @page. A running header on the left that tracks the current section — that is a GCPM named string, set by each heading. A page counter at the foot showing N of M. The cover page suppresses its header via @page :first.

Text, links and structure

The font is embedded and subset, so text is selectable and searchable and the file stays small. Links become real PDF annotations, one rectangle per line a link occupies. Headings become bookmarks in the reader's sidebar.
